# Leonida Logs images

Official GTA 6 images (Rockstar Games, PlayStation, Xbox), collected automatically every day at 04:00 IST by `.github/workflows/collect.yml`.

- `official/<source>/` — the images (JPG)
- `manifest.json` — one entry per image: file, credit, source page, size

Credit on posts: use the `credit` field (e.g. "Image: Rockstar Games").

Manual run: Actions tab → "Collect GTA 6 images" → Run workflow.
